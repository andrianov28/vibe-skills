# vibe-skills

Каталог скиллов курса «Вайб-сайты» (Академия Интернет Маркетинга) для Claude Code.

## Установка

### В приложении Claude (вкладка Code) – одной фразой

Скопируй и отправь Клоду:

```
Подключи каталог скиллов курса «Вайб-сайты»: добавь в мой файл настроек ~/.claude/settings.json marketplace vibe-skills (github, repo andrianov28/vibe-skills) в extraKnownMarketplaces и включи плагин kwork-podborka@vibe-skills в enabledPlugins. Потом скажи, что сделал.
```

После ответа Клода перезапусти приложение (или начни новый чат). Проверка: напиши «подбери заказы».

### В терминале Claude Code – двумя командами

```
/plugin marketplace add andrianov28/vibe-skills
/plugin install kwork-podborka@vibe-skills
```

### Что именно попадает в настройки

Файл `~/.claude/settings.json` (Windows: `C:\Users\<имя>\.claude\settings.json`), два ключа:

```json
{
  "extraKnownMarketplaces": {
    "vibe-skills": {
      "source": { "source": "github", "repo": "andrianov28/vibe-skills" }
    }
  },
  "enabledPlugins": {
    "kwork-podborka@vibe-skills": true
  }
}
```

Если в файле уже есть эти ключи, записи добавляются к существующим, ничего не удаляется. Следующие скиллы курса включаются строкой в `enabledPlugins`, например `"razbor-tz@vibe-skills": true`. Фраза Клоду для второго и следующих скиллов короче, каталог уже подключён:

```
Включи скилл razbor-tz из каталога vibe-skills: добавь в мой файл настроек ~/.claude/settings.json в enabledPlugins строку razbor-tz@vibe-skills: true. Потом скажи, что сделал.
```

### Обновление

Плагины из каталога обновляются автоматически при старте Claude Code. В терминале можно принудительно: `/plugin update kwork-podborka@vibe-skills`.

## Скиллы

| Скилл | Что делает | Урок |
|---|---|---|
| `kwork-podborka` | Сам читает биржу Kwork, отбирает свежие простые сайты, пишет черновики откликов | Д1.6 |
| `razbor-tz` | Разбирает ТЗ заказчика в бриф со слотами, с которого стартует сборка сайта | Д2.1 |
| `vibe-sait` | Собирает сайт по каркасу ниши (16 ниш от шиномонтажа до стоматологии): бриф → каркас и вариант → картинки kie.ai (или заглушки) → скриншоты → правки словами. Нужны Node.js 20+, Chrome и свой ключ kie.ai | Д2.2–Д2.3 |
| `vibe-publish` | Публикует сайт: живая ссылка на GitHub Pages за минуту (бесплатно, «опубликуй» / «откати») и перенос в Тильду одним блоком HTML-кода. Нужен аккаунт GitHub, для Тильды – тариф Personal | Д2.4 |
| `vibe-mockup` | Мокап сайта для портфолио и обложки кворка: ноутбук + телефон + подпись в палитре сайта, без нейросетей; тексты кворка и работ | Д2.5 |
| `ohotnik-karty` | Охотник: клиенты с Яндекс.Карт – бизнесы ниши без сайта или с заглушкой в любом городе, отзывы, цены, контакты «куда написать», индекс горячести, крючок из отзывов и первое сообщение; отчёт «Карта охоты» (HTML + CSV) | М4 |
| `vibe-video` | Видео-демо сайта: вертикальный ролик 30–50 секунд для владельца бизнеса вместо голой ссылки – живая прокрутка сайта в телефоне, рейтинг, цены, отзывы и фото из брифа, музыка через kie.ai (12 кредитов, без ключа – запасные треки), монтаж по битам в [HyperFrames](https://github.com/heygen-com/hyperframes). Нужны Node.js 22+ и Chrome, FFmpeg ставится сам | М5.5 |

Скиллы добавляются по мере выхода уроков.

Фраза для скилла сборки (третий скилл курса):

```
Включи скилл vibe-sait из каталога vibe-skills: добавь в мой файл настроек ~/.claude/settings.json в enabledPlugins строку vibe-sait@vibe-skills: true. Потом скажи, что сделал.
```

Фраза для скилла публикации (четвёртый скилл курса):

```
Включи скилл vibe-publish из каталога vibe-skills: добавь в мой файл настроек ~/.claude/settings.json в enabledPlugins строку vibe-publish@vibe-skills: true. Потом скажи, что сделал.
```

После включения в новом чате скажи «настрой публикацию»: скилл поставит GitHub CLI и откроет браузер для входа в GitHub кодом (пароли и токены в чат не вставлять). Дальше «опубликуй» даёт ссылку на сайт, «перенеси на Тильду» кладёт код блока в буфер обмена.

После включения скилла сборки в новом чате скажи «настрой сборку сайтов»: скилл сам поставит пакеты для скриншотов и картинок в папку ~/.vibe/build, найдёт Chrome и откроет файл `~/.vibe/.env`, куда ученик руками вставляет свой ключ kie.ai (в чат ключ не вставлять; без ключа сайты собираются на заглушках).

Фраза для скилла видео:

```
Включи скилл vibe-video из каталога vibe-skills: добавь в мой файл настроек ~/.claude/settings.json в enabledPlugins строку vibe-video@vibe-skills: true. Потом скажи, что сделал.
```

После включения в новом чате скажи «настрой видео»: скилл поставит движок ролика в папку ~/.vibe/video (HyperFrames, свой FFmpeg, около 850 МБ, один раз). Дальше «сделай видео по сайту» – и через несколько минут в папке сайта лежит `video/<Название>-ролик.mp4`.

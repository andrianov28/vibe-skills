# vibe-mockup – «Мокап для портфолио»

Скилл курса «Вайб-сайты»: делает из собранного сайта картинку для портфолио и обложки кворка на Kwork – ноутбук и телефон с первым экраном сайта, подпись, фон и шрифты в палитре самого сайта. Без нейросетей и кредитов: скриншоты снимает Chrome, композицию собирает скрипт.

Размер 1320×880 (обложка кворка требует минимум 660×440, 30 КБ – 10 МБ, jpg/png), на выходе png и jpg.

## Установка

```
/plugin install vibe-mockup@vibe-skills
```

или фразой в приложении Claude: «включи плагин vibe-mockup@vibe-skills в enabledPlugins моего settings.json». Нужны пакеты из папки сборки скилла «Вайб-сайт» («настрой сборку сайтов») и Google Chrome.

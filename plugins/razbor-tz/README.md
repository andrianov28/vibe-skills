# razbor-tz

Скилл курса «Вайб-сайты». Ученик вставляет описание заказа с биржи Kwork и говорит «разбери ТЗ». Скилл отвечает в пять частей: что заказчик сказал, что имел в виду (три «П» ниши), чего не хватает и что спросить (не больше трёх вопросов), стоп-сигналы, черновой бриф `brief.md` со слотами. С этого брифа стартует скилл сборки сайта.

Установка (подробно в README каталога):

```
/plugin install razbor-tz@vibe-skills
```

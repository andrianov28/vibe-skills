# Ниши: три «П», блоки, слова, мир

Для каждой ниши: **боль** клиента, **персона** (кто решает), **обещание** сайта, обязательные блоки, слова, которые продают, и запрещённые слова. Город, название, адрес, телефон, цены всегда слоты: `{{город}}`, `{{компания}}`, `{{адрес}}`, `{{телефон}}`, `{{цена}}`. У учеников разные города: **никакой географии в шаблоне**, только в данных клиента.

Все цифры ниже это условия услуги (нормы времени, гарантии), а не статистика. Статистику выдуманной компании не пишем.

---

## 1. Шиномонтаж
- **Боль:** сезон, очередь на два часа, «приезжайте, посмотрим», непонятная цена, испорченный диск.
- **Персона:** водитель 25–55, решает за минуту с телефона, ищет «шиномонтаж рядом», смотрит цену и можно ли записаться.
- **Обещание:** приезжаешь к своему времени, переобули за 25–30 минут, цена известна до приезда.
- **Блоки:** hero с записью → сезонная шкала (когда переобуваться: среднесуточная +7°) → услуги с ценами → как проходит (запись, приезд, стенд, выдача) → гарантии (балансировка в цене, датчики давления, хранение) → адрес, часы, запись.
- **Слова:** переобуть, балансировка, ремонт прокола, сезонное хранение, датчики TPMS, к своему времени.
- **Не писать:** «лучший в городе», «низкие цены», «профессионально».
- **Мир:** ноктюрн. **Палитра:** off-black + янтарь. **Грамматика:** фильм-лайт с hero из слоёв.

## 2. Ногти, бьюти
- **Боль:** «запись только через две недели», непонятно, что получится, страшно за стерильность, мастер молчит про цену.
- **Персона:** женщина 20–45, выбирает по фото работ и по ощущению «мой мастер», записывается в мессенджере.
- **Обещание:** покажем работы как есть, назовём цену сразу, запись на ближайшие дни, стерильность видна.
- **Блоки:** hero → галерея работ (лента) с фактами вместо лозунгов («гель-лак, 90 минут, {{цена}}») → услуги и цены → стерильность и материалы (факты: крафт-пакеты, автоклав, одноразовые пилки) → мастер → запись.
- **Слова:** маникюр, покрытие, укрепление, комбинированный, дизайн, снятие, запись на ближайшие дни.
- **Не писать:** «ноготочки» на сайте (это наше внутреннее), «премиум-салон», «волшебство».
- **Мир:** высокий ключ. **Палитра:** тёплый белый + терракота (или пудра + графит). **Грамматика:** галерея-каталог.

## 3. Строители (дома, бани, пристройки)
- **Боль:** страх, что бросят на полпути, смета вырастет вдвое, «сроки плюс-минус год».
- **Персона:** семья 30–50, решает пара, долго сравнивает, хочет видеть этапы и договор.
- **Обещание:** этапы и оплата по этапам, смета фиксируется в договоре, показываем стройку, а не рендеры.
- **Блоки:** hero → этапы стройки как главы (фундамент, коробка, кровля, отделка, сдача) → что входит в смету → материалы (факты) → объекты (слот под реальные фото) → расчёт стоимости (форма-слот).
- **Слова:** этапами, по договору, фиксированная смета, сдача по акту, брус/каркас/газоблок (по специализации).
- **Не писать:** «дом мечты», «под ключ» без расшифровки, «европейское качество».
- **Мир:** архитектурный. **Палитра:** холодный нейтральный + тёплое дерево. **Грамматика:** главы-журнал.

## 4. Ремонт квартир
- **Боль:** грязь, сроки, «прораб пропал», непонятно, что было и что стало.
- **Персона:** владелец квартиры 28–50, часто после покупки новостройки, хочет контроль без ежедневных приездов.
- **Обещание:** видно «было и стало», график по неделям, фотоотчёт, уборка после себя.
- **Блоки:** hero «было / стало» → как ведём ремонт (график, фотоотчёт, оплата этапами) → виды работ и цены за м² → материалы → объекты (слот) → расчёт.
- **Слова:** черновой, чистовой, косметический, за м², фотоотчёт, по графику, уборка после работ.
- **Не писать:** «евроремонт», «дизайнерский», «под ключ» без расшифровки.
- **Мир:** документальный. **Палитра:** off-white + кобальт. **Грамматика:** разделённая сцена (левая половина «было», правая «стало»).

## 5. Мебель на заказ (кухни, шкафы)
- **Боль:** «замерщик приедет через неделю», цена только после замера, фасады на картинке одни, привезли другие.
- **Персона:** семья 30–55 с новой квартирой или после ремонта, выбирает по картинке и материалу, боится переплатить.
- **Обещание:** посчитаем по размерам за день, покажем фасады вживую, срок изготовления в договоре.
- **Блоки:** hero → конфигуратор фасадов (цвет меняет картинку) → материалы (фасады, столешницы, фурнитура: факты) → как заказать (замер, проект, договор, изготовление, монтаж) → работы (слот) → расчёт.
- **Слова:** фасады, столешница, фурнитура (доводчики), замер, проект, срок изготовления.
- **Не писать:** «мебель премиум-класса», «итальянское качество», «эксклюзив».
- **Мир:** макро-текстура. **Палитра:** тёмный лес + кость + янтарь. **Грамматика:** фильм-лайт + pin-конфигуратор.

## Кандидаты 6–15 (заготовки)
Клининг (документальный, off-white + мята) · сантехник/электрик (ноктюрн или документальный, графит + оранжевый) · автосервис/детейлинг (жёсткий свет, чёрный + серебро) · окна-потолки-кухни (архитектурный, белый + тёплый серый) · грузоперевозки (документальный, синий + песок) · парикмахерские (высокий ключ, крем + графит) · цветы (макро, тёмный лес + пудра) · ателье (макро, лён + чернила) · репетиторы (высокий ключ, бумага + чернила + один цвет) · фитнес-тренеры (жёсткий свет, чёрный + лайм).

Правило смежной ниши: ученик берёт ближайший шаблон и меняет три «П», слова и мир. Скилл «Сборка по номеру» адаптирует.

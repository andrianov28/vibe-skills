# Радар заказов

Ученик курса «Вайб-сайты» хочет первым видеть заказы на сайты. Радар делает две вещи:
1. **Telegram – только прямые заказчики.** Люди и компании, которые сами пишут «нужен сайт / кто сделает лендинг» с контактом. Зеркала бирж (каналы, которые перепечатывают Kwork, FL.ru, Freelancehunt) отсеиваем: Kwork радар читает напрямую, а через Telegram это те же заказы с опозданием.
2. **Kwork** – свежая лента скиллом «Подборка заказов на Kwork» (kwork-podborka) по его правилам.

Сводка приходит **от бота ученика** (скилл «Бот-продавец», vibe-bot) – двумя блоками: «Telegram» и «Kwork», к каждому заказу готов отклик.

Скрипты – в папке этого скилла: `scripts/radar.mjs` (Node) и `scripts/tg-web.js` (помощник для Telegram Web). Данные радара – `~/.vibe/radar/` (мои каналы, что уже присылали, сводки). Тире в текстах – короткое «–».

## Что нужно заранее

- **Telegram Web во встроенном браузере** (web.telegram.org/k/), ученик вошёл в свой аккаунт: QR-код с телефона (Настройки → Устройства → Подключить устройство). Облачный пароль Telegram ученик вводит **сам** – ты пароли не вводишь и не просишь. Открывай только версию `/k/`: переход на `/a/` сбрасывает вход.
- **Бот ученика** (урок про бота): папка бота с `.env` и `bot.json`, в нём запомнен чат владельца («запомни мой чат»).
- **Витрина** ученика – её адрес идёт в отклики заказчикам из Telegram.

Первый раз: `node "<скилл>/scripts/radar.mjs" init --vitrina <адрес витрины> --bot "<папка бота>"`. Адрес витрины ищи в папке витрины (файл `.publish` / `vitrina.json`) или спроси одной строкой. Проверка – `radar.mjs check`.

## «Найди мне каналы с заказами» / «обнови мои каналы»

Ниша и город ученика здесь **не важны** – ищем все заказы на сайты. Списки у учеников всё равно получаются разными: фразы поиска у каждого свои, а «похожие каналы» ведут в разные стороны.

1. Открой Telegram Web (`/k/`) во встроенном браузере. Если на экране вход по QR или пароль – попроси ученика войти и подожди «готово».
2. Прочитай файл `scripts/tg-web.js` и выполни его текст целиком в `javascript_tool` – появится `vibeRadar`.
3. Фразы: `node radar.mjs frazy --n 3` (для поиска по постам) и 4–5 своих коротких для поиска чатов («заказы сайты», «фриланс заказы», «фриланс чат», «ищу разработчика», «заказы на сайт»).
4. `await vibeRadar.najti([фразы для постов], [фразы для чатов])` – кандидаты. Поиск по постам всех каналов Telegram даёт **10 бесплатных поисков в день**, дальше Telegram просит Stars – помощник тратит только бесплатные и сам пропускает остальное. Больше 3 поисков по постам за раз не делай.
5. Если в «моих каналах» уже есть годные – добавь `await vibeRadar.pohozhie([...годные])` («похожие каналы»), из найденного бери каналы и чаты со словами фриланс / заказы / работа / удалёнка / сайт / веб / дизайн / tilda в названии (не больше 40).
6. Чтение кандидатов долгое (по 10 штук ~30 с) – запускай в фоне страницы:
   ```js
   window._read=null; (async()=>{const all=[];const list=[…адреса без @…];for(let i=0;i<list.length;i+=10){all.push(...await vibeRadar.prochitat(list.slice(i,i+10),60));window._prog=all.length;}window._read=all;})(); 'ok'
   ```
   и забирай `window._prog`, пока `window._read` не готов. Готовый `JSON.stringify(window._read)` сохрани в файл `~/.vibe/radar/kandidaty.json` (если ответ большой – забирай частями `.slice(…)`).
7. `node radar.mjs ocenka --file "~/.vibe/radar/kandidaty.json"` – вердикт по каждому: годен / зеркало биржи / мёртвый / нет заказов на сайты, и примеры прямых заказов.
8. Годные – в список: `node radar.mjs kanaly add @a @b …` (группы – с `--group`). Держи 5–15 каналов. Покажи ученику таблицу: канал, сколько прямых заказов на сайты за последние посты, пример заказа.
9. Честно одной строкой: «Прямых заказов в Telegram немного – обычно несколько в неделю на весь список. Радар ценен тем, что видит их в первые часы и сразу даёт отклик».

## «Включи радар»

Один вопрос сообщением: во сколько присылать сводку (по умолчанию 7:00). Объясни коротко: «Радар работает, пока открыт Claude Code: можно оставить компьютер на ночь или включить утром – радар догонит сам. Каналы читаются из Telegram Web во встроенном браузере – вы там уже вошли».

Создай задачу по расписанию (scheduled-tasks: create_scheduled_task): `taskId` – `radar-zakazov`, `title` – «Радар заказов», `cronExpression` по времени (7:00 → `0 7 * * *`), промпт – шаблон из `references/radar-zadacha.md` с полными путями. Предложи сразу «запусти радар сейчас» (Run now), чтобы увидеть первую сводку.

«Выключи радар» – `update_scheduled_task` с `enabled: false` (не удалять). «Включи снова» – `enabled: true`. «Поменяй время радара» – новое расписание.

## «Покажи заказы» / сводка вручную

То же, что делает задача по расписанию (`references/radar-zadacha.md`), только сразу и в чате; в конце спроси, отправить ли сводку ботом.

## Сводка – как писать

```
☀️ Радар заказов · 28 октября

TELEGRAM – прямые заказчики (2)

1. Нужен лендинг для сообщества, 3 000 ₽, 2 дня
Где: @vakansi_rus · 3 ч назад · https://t.me/vakansi_rus/1234
Кому писать: @lanadel3456
Отклик:
Здравствуйте! Увидел ваш пост про лендинг для сообщества. Соберу за 2 дня по вашей структуре и референсу: … Мои работы: <витрина>. Когда удобно обсудить?

KWORK (3)

1. 🔥 Сайт-визитка для клининга · 8 000–24 000 ₽ · откликов 4 · 2 ч
https://kwork.ru/projects/…
Отклик: …

Отклик в Kwork = коннект. Сначала 🔥.
```

Правила:
- **Telegram:** отклик 3–4 предложения: первое – про его задачу своими словами, второе – что сделаешь и срок, третье – ссылка на витрину ученика целиком («Мои работы: <витрина>»), в конце один вопрос. Без «Здравствуйте, меня зовут…», без демо-сайта (у прямых заказчиков мало данных для демо). Если контакта нет – «писать в комментарии к посту / автору группы».
- **Осторожно:** просят предоплату с вашей стороны, «тестовое за свой счёт», переход на сторонние сайты для «регистрации исполнителя» – ставь ⚠️ «похоже на развод». Деньги ученик не платит никогда.
- **Kwork:** отбор и отклики строго по правилам скилла «Подборка заказов на Kwork» (простые сайты с нуля, 3–30 тыс., свежесть, коннекты). Не больше 5 заказов.
- Пустой блок – так и пиши: «Telegram: новых прямых заказов за ночь нет».
- Ты **никому не пишешь и не откликаешься** от имени ученика – ни в Telegram, ни на Kwork. Сводку отправляет только бот ученика самому ученику.

## Команды скрипта

```
node radar.mjs init --vitrina <адрес> --bot "<папка бота>"
node radar.mjs check
node radar.mjs frazy --n 3
node radar.mjs ocenka @канал1 @канал2          (публичные каналы с t.me, без браузера)
node radar.mjs ocenka --file kandidaty.json    (каналы и группы, прочитанные в Telegram Web)
node radar.mjs kanaly | kanaly add @a --group | kanaly remove @a
node radar.mjs sbor --hours 24 --import prochitano.json
node radar.mjs kwork
node radar.mjs svodka "<файл сводки .md>"
```

## Обновление скиллов курса («обнови скиллы»)

Ученик говорит «обнови скиллы» – выполни `node ~/.claude/plugins/marketplaces/vibe-skills/update.mjs` (на Windows: `node "%USERPROFILE%\.claude\plugins\marketplaces\vibe-skills\update.mjs"`). В ответ – список скиллов с версиями из вывода и фраза «новые версии подхватятся в новом чате».

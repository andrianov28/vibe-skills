# vibe-sait

Скилл курса «Вайб-сайты». Собирает одностраничный сайт малого бизнеса, который выглядит как сделанный студией: готовый каркас ниши со скролл-сценами, картинки под мир ниши, проверка скриншотами на компьютере и телефоне, упаковка в блок Тильды.

Что говорить Клоду:

- «настрой сборку сайтов» – один раз на компьютер: ставит пакеты для скриншотов и картинок, проверяет Chrome и ключ kie.ai, показывает баланс кредитов;
- «проверь ключ kie» / «открой файл ключа» – ключ kie.ai лежит только в файле `~/.vibe/.env`, который скилл готовит и открывает в Блокноте; ключ вставляется туда руками, в чат он не попадает;
- «собери сайт» – берёт `brief.md` из папки, которую сделал скилл «Разбери ТЗ», выбирает каркас ниши и вариант (палитра, первый экран, заголовок), генерирует картинки, проверяет и даёт адрес для просмотра;
- «другой вариант», «поменяй заголовок на …», «перегенерируй картинку …», «перенеси на Тильду» – доработки.

Без ключа kie.ai сайт собирается на нейтральных заглушках вместо фото, настоящие картинки добавляются позже одной фразой.

Что нужно на компьютере: Node.js 20+ (nodejs.org, LTS), Google Chrome. Ключ kie.ai – свой у каждого, пополняется на kie.ai.

Каркасы ниш в комплекте: шиномонтаж, ногти и бьюти, строители, ремонт квартир, мебель на заказ. Смежные ниши собираются на ближайшем каркасе, остальные – по справочнику из 16 ниш.

Установка (подробно в README каталога):

```
/plugin install vibe-sait@vibe-skills
```

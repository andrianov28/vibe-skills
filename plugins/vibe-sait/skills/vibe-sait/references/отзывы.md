# Блок отзывов: честные слоты под настоящие отзывы с Яндекс.Карт

Выдуманные отзывы не пишем никогда. Блок проектируется так, чтобы выглядеть законченным, а тексты, имена, даты и рейтинг подставляет скилл «Сборка по номеру» из карточки клиента на Яндекс.Картах (или ученик руками). Подача честная: «Отзывы с Яндекс.Карт», ссылка на карточку, рейтинг слотом.

## Слоты
`{{рейтинг}}` (например 4,8) · `{{отзывов}}` (число) · `{{ссылка-карты}}` · по каждому отзыву: `{{имя 1}}`, `{{дата 1}}`, `{{отзыв 1}}`, `{{оценка 1}}` (1–5). Три отзыва в шаблоне, при заполнении можно больше.

## Правила
- Не сетка одинаковых карточек-визиток. Варианты: три цитаты разного размера в асимметричной сетке; одна крупная цитата и две малые; вертикальный список с линиями; лента рядом с рейтингом.
- Заголовок блока про факт, а не про лозунг: «Что пишут на Яндекс.Картах», не «Нам доверяют».
- Рядом с заголовком плашка рейтинга: крупная цифра `{{рейтинг}}`, звёзды CSS-ом (без эмодзи и картинок), подпись «{{отзывов}} отзывов на Яндекс.Картах» и ссылка «Читать все отзывы» на `{{ссылка-карты}}`.
- Имя и дата мелко, текст читаемым кеглем (не меньше базового), кавычки типографские «».
- Появление через `data-v-in` со stagger, никаких каруселей и автопрокрутки.
- Если у клиента отзывов нет, блок не показываем совсем (в брифе отметить).

## Готовая разметка (адаптируй классы под сайт)

```html
<section class="v-section" data-v-act="flow" id="otzyvy" aria-label="Отзывы с Яндекс.Карт">
  <div class="v-wrap reviews">
    <div class="reviews__head" data-v-in data-v-stagger="60">
      <h2 class="v-display v-display--md">Что пишут на Яндекс.Картах</h2>
      <div class="reviews__rating">
        <span class="reviews__num v-nums">{{рейтинг}}</span>
        <span class="reviews__stars" style="--r: {{рейтинг}}" aria-label="рейтинг {{рейтинг}} из 5"></span>
        <span class="v-soft">{{отзывов}} отзывов</span>
        <a href="{{ссылка-карты}}" rel="noopener">Читать все отзывы</a>
      </div>
    </div>
    <ul class="reviews__list" data-v-in data-v-stagger="90">
      <li class="reviews__item reviews__item--big">
        <p class="reviews__text">«{{отзыв 1}}»</p>
        <p class="reviews__meta"><b>{{имя 1}}</b> · {{дата 1}} · <span class="reviews__stars reviews__stars--sm" style="--r: {{оценка 1}}"></span></p>
      </li>
      <li class="reviews__item">
        <p class="reviews__text">«{{отзыв 2}}»</p>
        <p class="reviews__meta"><b>{{имя 2}}</b> · {{дата 2}} · <span class="reviews__stars reviews__stars--sm" style="--r: {{оценка 2}}"></span></p>
      </li>
      <li class="reviews__item">
        <p class="reviews__text">«{{отзыв 3}}»</p>
        <p class="reviews__meta"><b>{{имя 3}}</b> · {{дата 3}} · <span class="reviews__stars reviews__stars--sm" style="--r: {{оценка 3}}"></span></p>
      </li>
    </ul>
  </div>
</section>
```

Для светлых страниц звёзды и линии наследуют токены, ничего менять не нужно. Для журнальной грамматики блок ставится как отдельная глава «Отзывы» с интертитром, для галереи как экспонат-плашка в конце ленты или отдельная секция.

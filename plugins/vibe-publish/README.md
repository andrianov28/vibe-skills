# vibe-publish – «Публикация сайта»

Скилл курса «Вайб-сайты»: выкладывает сайт, собранный скиллом «Вайб-сайт», в интернет.

- **GitHub Pages** – основной дом сайта. Бесплатно, ссылка через минуту, правки и откат по одной фразе: «опубликуй», «откати», «история публикаций».
- **Тильда** – опция сдачи заказчику: «перенеси на Тильду» собирает один блок HTML-кода с картинками с GitHub и кладёт его в буфер обмена, ученик вставляет блок T123 и публикует.

## Установка

Каталог `vibe-skills` уже подключён (см. корневой README). Включить плагин:

```
/plugin install vibe-publish@vibe-skills
```

или фразой в приложении Claude: «включи плагин vibe-publish@vibe-skills в enabledPlugins моего settings.json».

## Что нужно ученику

- Аккаунт на GitHub (бесплатно). Разовая настройка: «настрой публикацию» – скилл ставит GitHub CLI (Windows: winget, Mac: скачивает сам) и открывает браузер для входа кодом. Пароли и токены в чат не вставляются.
- Для Тильды: тариф Personal и выше (на бесплатном нет вставки HTML-кода).

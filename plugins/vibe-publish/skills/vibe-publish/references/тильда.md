# Вывод в Тильду

Проверено 03.09.2026 по справке Тильды; порядок с GitHub Pages добавлен 11.09.2026. Живая вставка в редактор Тильды – проверить на тестовом аккаунте (см. памятку внизу).

## Схема
Сайт сначала публикуется на GitHub Pages (`scripts/publish.mjs`): там живут страница и все картинки по постоянным адресам `https://<логин>.github.io/<имя>/assets/…`. В Тильду переезжает только код: один блок **T123 «HTML-код»** (раздел «Другое»), в нём разметка, стили и движок, картинки грузятся с GitHub. Поэтому в Тильду ничего не загружается, ссылки не копируются. Пока репозиторий ученика на месте, страница в Тильде работает.

Тариф: T123 есть на Personal и выше, на Free вставки HTML-кода нет.

## Блок T123
**Лимит 100 000 байт на блок.** `scripts/tilda-pack.mjs <папка> --clip` собирает `tilda.html`, считает байты, кладёт код в буфер и печатает четыре действия. Если код больше лимита: убрать один блок из сайта (по согласованию с учеником) и собрать снова. Делить на два блока T123 можно (в первом стили и первая половина разметки, во втором остальное и движок), но это запасной путь: движок монтируется один раз, `Vibe.mount(document.querySelector('.v-page'))`.

Четыре действия в Тильде: создать страницу → добавить блок «Другое» → T123 → в блоке «Контент» вставить код → «Опубликовать». Правка после переноса: новый код тем же путём в тот же блок (выделить всё, вставить).

## Шрифты
В блоке шрифты не подключаем. Настройки сайта → «Шрифты и цвета» → выбрать ту же пару, что в коде (скрипт печатает названия). В библиотеке Тильды есть Google Fonts с кириллицей: Manrope, Unbounded, Onest, Golos, Oswald, IBM Plex, Rubik. Если пары нет в библиотеке: Настройки сайта → Ещё → «HTML-код для head» → вставить `<link>` Google Fonts из `<head>` нашего index.html (на Personal это доступно). В коде шрифты указаны по имени с системным запасным стеком, подхватятся сами.

## Видео
Тильда принимает mp4/webm только до 5 МБ, поэтому видео на скролле не используем. Слои, шторки и появление текста дают ощущение движения без видео.

## Если ученик говорит, что в Тильде что-то не так
Проверять страницу Тильды скриншотами скилл не должен: ученик смотрит сам. Типовые жалобы:
1. «Сцены не прилипают, всё едет сплошняком» – у обёртки Тильды `overflow: hidden`. Добавить в начало кода блока `<style>.t-rec, .t-body { overflow: visible !important; }</style>` и дать ученику код заново.
2. «Сверху пустая полоса / шапка Тильды наезжает» – если у сайта стандартная шапка Тильды, удалить из кода `[data-v-progress]` (полоса прогресса закреплена относительно окна).
3. «На телефоне дёргается первый экран» – высота сцены `100svh`, это норма адресной строки; если дёргает сильно, заменить `100svh` на `100dvh` в стилях блока.
4. «На телефоне горизонтальная прокрутка» – `.v-page { overflow-x: clip }` должен стоять; если обёртка Тильды шире, добавить `.t-rec { overflow-x: clip; }` в тот же `<style>`.
5. «Картинок нет» – сайт не опубликован (в коде `{{ASSETS}}/`) или репозиторий удалён: «опубликуй» и собрать код снова.
Проверить с настоящего телефона: это другая машина, а не эмулятор.

## Страницы под клиентов
На одном аккаунте Тильды ученик держит сайт-витрину и по странице на каждого потенциального клиента: `/potolki-{{компания}}`. Один блок T123 на страницу. На GitHub при этом по репозиторию на клиента, имена латиницей из папок сайтов.

## Сдача заказчику
Два пути, выбирает заказчик:
- **Ссылка без Тильды.** Сайт на GitHub Pages со своим доменом заказчика (Settings → Pages → Custom domain, запись CNAME в DNS домена делает владелец). Бесплатно. Правки – через ученика: «опубликуй».
- **Тильда без зависимости от GitHub.** Картинки загружаются в Тильду (Настройки сайта → «Файлы для скачивания», из папки `assets/` сайта), ученик присылает скиллу ссылки на файлы, скилл собирает код с этими адресами. Подробно: инструкция «Сдача сайта заказчику в Тильде» в материалах урока Д2.4. После этого репозиторий GitHub можно удалить, страница в Тильде живёт сама.

## Памятка: что проверить на живой Тильде (не сделано на 11.09.2026)
Вставить `tilda.html` потолков в T123 на аккаунте Personal и посмотреть: прилипание сцен, первый экран на телефоне, шрифты после выбора пары, как выглядит раздел «Файлы для скачивания» и можно ли забрать ссылки на все файлы разом.

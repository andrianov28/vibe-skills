# Перенос в Тильду автоматически – порядок действий для Клода

Проверено в живой Тильде 02.10.2026 (тариф Personal, пробный период): сайт «по номеру» TyreGeek перенесён с нуля на чистую страницу, картинки из Тильды, шрифты Google Fonts, кнопка WhatsApp с номером, ссылок на GitHub ноль.

Инструменты – «Claude в Chrome» (`mcp__claude-in-chrome__*`): `tabs_context_mcp`, `navigate`, `find`, `computer`, `read_page`, `javascript_tool`, `file_upload`. Если они отложены – загрузи одним вызовом ToolSearch. Работай в своей вкладке (группа вкладок Claude): вход в Тильду в Chrome общий, вкладку ученика трогать не нужно. Кнопки ищи через `find` по названию, а не по координатам: Тильда переставляет интерфейс.

## 0. Проверки до первого клика

1. `tabs_context_mcp` (с `createIfEmpty: true`). Ответ «not connected» – стоп: «Расширение Claude в Chrome не подключено. Откройте Chrome, нажмите значок Claude справа от адресной строки и войдите тем же аккаунтом, что в Claude Code. Скажите "готово"». Если расширение привязано к другому аккаунту – выйти на claude.ai в Chrome и войти заново.
2. Открой `https://tilda.cc/projects/`. Если там вход/регистрация – стоп: «Войдите в свою Тильду в Chrome и скажите "готово"». Пароль не вводить никогда.
3. Сайтов несколько – спроси, в какой класть страницы клиентов (один вопрос), запомни в `<папка сайта>/.publish/tilda.json` (`projectid`). Один сайт – бери его.
4. Данные страницы:
   - **адрес** (латиница, дефисы): `name` из `.publish/publish.json`, если сайт публиковался; иначе название бизнеса из brief.md латиницей (TyreGeek → `tyregeek`);
   - **название**: «Компания – Город – ниша» из brief.md (`TyreGeek – Таганрог – шиномонтаж`), тире короткое;
   - **картинки**: все файлы из `<папка сайта>/assets/` кроме папки `fonts/` (webp/jpg/png/svg).

## 1. Страница: найти или создать

Открой `https://tilda.cc/projects/?projectid=<id>`. В списке страниц видна колонка адреса (`/tyregeek`).
- **Адрес уже есть** (обновление сайта) – открой эту страницу (клик по названию → редактор) и переходи к шагу 2, догружая только новые картинки, потом шаг 4 – заменить код в существующем блоке T123.
- **Нет** – `find` «Создать новую страницу» → клик → в шаблонах `find` «Выбрать» у карточки «Пустая страница» → откроется редактор, в адресе вкладки `pageid=…`.

Сразу настройки: `find` «Настройки» (верхнее меню редактора) → поля «Заголовок страницы» и адрес страницы (поле с подсказкой `pageNNN.html` рядом с `https://<сайт>.tilda.ws/`): тройной клик → ввести → «Сохранить изменения».

## 2. Галерея с картинками

1. Нижняя панель быстрых блоков → «Галерея». ВНИМАНИЕ: клик по ref из `find` тут не срабатывает – сделай скриншот и кликни по координатам надписи «Галерея» в панели. Встанет GL01 с четырьмя фото-заглушками Тильды.
2. Навести мышь на галерею (`computer hover`) → `find` «Контент» блока галереи → клик. Слева откроется панель «Список изображений».
3. Поле загрузки – единственный `input[type=file]` с `multiple`. Пометь его и найди:
   ```js
   [...document.querySelectorAll('input[type=file]')].find(x => x.multiple).setAttribute('aria-label', 'vibe-upload-multi')
   ```
   `find` «file input with aria-label vibe-upload-multi» → `file_upload` с путями ко всем картинкам. Лимит одного вызова 10 МБ – больше разбей на несколько вызовов. Подожди 5 секунд.
4. Удали заглушки: в каждой строке списка корзина «Удалить», без подтверждения. Удаляй строки, чьё имя файла не из `assets/`. Проверка списка:
   ```js
   [...document.body.innerText.matchAll(/\d{12}\/([\w.-]+\.(?:webp|jpg|jpeg|png|svg))/g)].map(m => m[1])
   ```
   Должны остаться ровно файлы сайта.
5. `find` «Сохранить и закрыть» → клик.

## 3. Публикация и код

1. «Опубликовать» (верхнее меню) → в окне «Публикация прошла успешно» `find` публичную ссылку (`https://<сайт>.tilda.ws/<адрес>`). Закрыть окно – Escape.
2. `node "<скилл>/scripts/tilda-pack.mjs" "<папка сайта>" --tilda "<публичная ссылка>" --clip` – код в буфере обмена. В выводе должно быть «Ссылок на GitHub в коде нет». «НЕ ЗАГРУЖЕНЫ …» – вернись в шаг 2.3 и догрузи.

## 4. Блок HTML-кода T123

1. Новый блок: `find` «Все блоки» (внизу страницы) → `scroll_to` + клик → в библиотеке `find` «Другое» → `scroll_to` + клик → `find` «T123» → `scroll_to` + клик. Блок встанет на страницу (под галереей – это нормально, галерея скрыта).
   При обновлении блок уже есть – этот пункт пропусти.
2. Навести на блок T123 → `find` «Контент» блока T123 → клик.
   **Первый раз Тильда может показать «Доступ к этому блоку ограничен. Подтвердите номер телефона»** – стоп: «Тильда просит подтвердить телефон – это один раз и только вами: введите номер и код из СМС в окне Тильды, скажите "готово"». Номер не вводить.
3. Редактор кода – Ace, слева. Клик в поле → `ctrl+a` → `ctrl+v` (код из буфера, шаг 3.2). Проверка, что вставилось всё:
   ```js
   const v = ace.edit(document.querySelector('.ace_editor')).getValue(); ({ len: v.length, start: v.slice(0, 60), github: /github/.test(v) })
   ```
   Начало – `<!-- Вайб-сайт: HTML-блок T123. Картинки: из Тильды -->`, github – false.
4. `find` «Сохранить и закрыть» → клик → «Опубликовать» → Escape.

## 5. Проверка опубликованной страницы

Открой публичную ссылку в своей вкладке, подожди 2–3 секунды:
```js
let opened = []; const o = window.open; window.open = (u) => { opened.push(u.slice(0, 40)); return null };
document.querySelector('[data-s-msg=whatsapp]')?.click(); window.open = o;
({ h1: document.querySelector('h1')?.textContent,
   github: performance.getEntriesByType('resource').filter(r => /github/.test(r.name)).length,
   fonts: [...new Set([...document.fonts].filter(f => f.status === 'loaded').map(f => f.family))],
   recs: [...document.querySelectorAll('.t-rec')].map(r => r.id + ':' + getComputedStyle(r).display),
   whatsapp: opened })
```
Норма: github 0, шрифты сайта загружены, галерея `display:none`, WhatsApp с номером (у каркасов без кнопок WhatsApp – пусто, это нормально). Картинки ниже первого экрана в фоновой вкладке не грузятся (ленивая загрузка) – это не ошибка; глазами проверяй скриншотом после прокрутки. Один скриншот первого экрана – ученику вместе со ссылкой.

## Ловушки (02.10.2026)

- Расширение после переустановки приложения может остаться привязанным к старому аккаунту Claude – «not connected». Лечится выходом и входом на claude.ai в Chrome.
- Окно Chrome свёрнуто – скриншоты не снимаются, клики уходят в пустоту. Попроси развернуть окно Chrome.
- Тильда держит имя файла в ссылке (`static.tildacdn.pub/tild…/hero.webp`), webp принимает. Скрипт сопоставляет по имени – файлы не переименовывай.
- Галерею не удалять: картинки живут в ней, при передаче страницы заказчику уезжают вместе со страницей.
- Пробный период Тильды (14 дней) переносу не мешает: T123 доступен на пробном Personal.

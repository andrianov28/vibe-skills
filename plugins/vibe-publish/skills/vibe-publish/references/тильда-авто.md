# Перенос в Тильду автоматически – порядок действий для Клода

Проверено в живой Тильде 02–03.10.2026 (тариф Personal, пробный период): TyreGeek и автомойка AVmasters перенесены с нуля на чистые страницы, картинки из Тильды, шрифты Google Fonts, кнопка WhatsApp с номером, ссылок на GitHub ноль. Время – 5–6 минут.

Инструменты – «Claude в Chrome» (`mcp__claude-in-chrome__*`): `tabs_context_mcp`, `navigate`, `find`, `computer`, `read_page`, `javascript_tool`, `file_upload`. Если они отложены – загрузи одним вызовом ToolSearch. Работай в своей вкладке (группа вкладок Claude): вход в Тильду в Chrome общий, вкладку ученика трогать не нужно. Кнопки ищи через `find` по названию. Если клик по ref ничего не изменил (так бывает у «Создать новую страницу», «Галерея», «Все блоки», «Опубликовать») – сделай скриншот и кликни по координатам этой кнопки. После каждого шага проверяй результат (скриншот или JS), а не верь клику. Скриншот завис по тайм-ауту – подожди 3 секунды и повтори или проверь состояние через JS.

## 0. Проверки до первого клика

1. `tabs_context_mcp` (с `createIfEmpty: true`). Ответ «not connected» – стоп: «Расширение Claude в Chrome не подключено. Откройте Chrome, нажмите значок Claude справа от адресной строки и войдите тем же аккаунтом, что в Claude Code. Скажите "готово"». Если расширение привязано к другому аккаунту – выйти на claude.ai в Chrome и войти заново.
2. Открой `https://tilda.ru/projects/` (tilda.cc сам перекинет туда же). Если там вход/регистрация – стоп: «Войдите в свою Тильду в Chrome и скажите "готово"». Пароль не вводить никогда.
3. Сайтов несколько – спроси, в какой класть страницы клиентов (один вопрос). Один сайт – бери его, ничего не спрашивай и никуда не записывай.
4. Данные страницы:
   - **адрес** (латиница, дефисы): поле `repo` из `.publish/publish.json`, если сайт публиковался по ссылке (TyreGeek → `tiregeek`); иначе название бизнеса из brief.md латиницей. Всегда маленькими буквами, пробелы → дефисы (TyreGeek → `tyregeek`, AVmasters → `avmasters`);
   - **название**: «Компания – Город – ниша» из brief.md (`TyreGeek – Таганрог – шиномонтаж`), тире короткое;
   - **картинки**: все файлы из `<папка сайта>/assets/` кроме папки `fonts/` (webp/jpg/png/svg).

## 1. Страница: найти или создать

Открой `https://tilda.ru/projects/?projectid=<id>`. В списке страниц видна колонка адреса (`/tyregeek`).
- **Адрес уже есть** (обновление сайта) – открой эту страницу (клик по названию → редактор) и переходи к шагу 2, догружая только новые картинки, потом шаг 4 – заменить код в существующем блоке T123.
- **Нет** – «Создать новую страницу» (оранжевая кнопка справа вверху; клик по ref обычно не срабатывает – кликай по координатам со скриншота) → в шаблонах `find` «Выбрать» у карточки «Пустая страница» → откроется редактор, в адресе вкладки `pageid=…`.

Сразу настройки: `find` «Настройки» (верхнее меню редактора) → поля «Заголовок страницы» и адрес страницы (поле с подсказкой `pageNNN.html` рядом с `https://<сайт>.tilda.ws/`): тройной клик → ввести → «Сохранить изменения». Кнопок «Сохранить изменения» в окне три (по одной на вкладку) – жми видимую, по координатам со скриншота.

## 2. Галерея с картинками

1. Нижняя панель быстрых блоков → «Галерея». ВНИМАНИЕ: клик по ref из `find` тут не срабатывает – сделай скриншот и кликни по координатам надписи «Галерея» в панели. Встанет GL01 с четырьмя фото-заглушками Тильды.
2. Прокрути страницу к началу блока галереи (панель блока «Контент / Настройки» висит у его верхнего края), наведи мышь на верх блока (`computer hover`) → `find` «кнопка Контент на панели блока» → клик. Запрос «Контент блока галереи» возвращает сам блок, а не кнопку. Слева откроется панель «Список изображений».
3. Поле загрузки – единственный `input[type=file]` с `multiple`. Пометь его и найди:
   ```js
   [...document.querySelectorAll('input[type=file]')].find(x => x.multiple).setAttribute('aria-label', 'vibe-upload-multi')
   ```
   `find` «file input with aria-label vibe-upload-multi» → `file_upload` с путями ко всем картинкам. Лимит одного вызова 10 МБ – больше разбей на несколько вызовов. Подожди 5 секунд.
4. Удали заглушки: в каждой строке списка корзина «Удалить», без подтверждения. Удаляй строки, чьё имя файла не из `assets/`. Проверка списка:
   ```js
   [...document.body.innerText.matchAll(/\d{12}\/([\w.-]+\.(?:webp|jpg|jpeg|png|svg))/g)].map(m => m[1])
   ```
   Должны остаться ровно файлы сайта.
5. `find` «Сохранить и закрыть» → клик.

## 3. Публикация и код

1. «Опубликовать» (верхнее меню справа; `find` даёт два элемента – кликай по координатам) → **подожди 6–8 секунд**: окно публикации сначала пустое. Ссылку бери через JS:
   ```js
   [...document.querySelectorAll('a')].map(a => a.href).filter(h => /tilda.ws/.test(h))
   ```
   Закрыть окно – Escape.
2. `node "<скилл>/scripts/tilda-pack.mjs" "<папка сайта>" --tilda "<публичная ссылка>" --auto --clip` – код в буфере обмена. Ключ `--auto` убирает из вывода ручную инструкцию «4 действия» – при автопереносе её не выполнять и ученику не пересказывать. В выводе должно быть «Ссылок на GitHub в коде нет». «НЕ ЗАГРУЖЕНЫ …» – вернись в шаг 2.3 и догрузи.

## 4. Блок HTML-кода T123

1. Новый блок: «Все блоки» – чёрная кнопка слева в панели быстрых блоков внизу страницы. `find` её не находит (возвращает блоки подвала) – прокрути вниз (`scroll`), сделай скриншот и кликни по координатам → в библиотеке `find` «Другое» → `scroll_to` + клик → `find` «T123» → `scroll_to` + клик. Блок встанет на страницу (под галереей – это нормально, галерея скрыта).
   При обновлении блок уже есть – этот пункт пропусти.
2. Прокрути блок T123 в центр экрана через JS:
   ```js
   [...document.querySelectorAll('.record')].pop()?.scrollIntoView({ block: 'center' })
   ```
   (новый блок – последний на странице; при обновлении ищи запись, где видна подсказка «Код будет выполнен на опубликованной странице»). Наведи мышь на блок по координатам со скриншота → `find` «кнопка Контент блока T123» → клик.
   **Первый раз Тильда может показать «Доступ к этому блоку ограничен. Подтвердите номер телефона»** – стоп: «Тильда просит подтвердить телефон – это один раз и только вами: введите номер и код из СМС в окне Тильды, скажите "готово"». Номер не вводить.
3. Редактор кода – Ace, слева. **Клик в СЕРЕДИНУ поля кода** (не у края и не у номеров строк) и проверь фокус:
   ```js
   document.activeElement.className
   ```
   Должно быть `ace_text-input`. Иначе кликни ещё раз в середину поля. Только с фокусом в Ace: `ctrl+a` → `ctrl+v` (код из буфера, шаг 3.2). Без фокуса Ctrl+A выделяет всю страницу Тильды и вставка молча не проходит. Проверка, что вставилось всё:
   ```js
   const v = ace.edit(document.querySelector('.ace_editor')).getValue(); ({ len: v.length, start: v.slice(0, 60), github: /github/.test(v) })
   ```
   Начало – `<!-- Вайб-сайт: HTML-блок T123. Картинки: из Тильды -->`, github – false, len не меньше 30 000 (len 0 – вставка не прошла, повтори с фокусом).
4. `find` «Сохранить и закрыть» → клик → «Опубликовать» → Escape.

## 5. Проверка опубликованной страницы

Открой публичную ссылку в своей вкладке, подожди 2–3 секунды:
```js
let opened = []; const o = window.open; window.open = (u) => { opened.push(u.slice(0, 40)); return null };
document.querySelector('[data-s-msg=whatsapp]')?.click(); window.open = o;
({ h1: document.querySelector('h1')?.textContent,
   github: performance.getEntriesByType('resource').filter(r => /github/.test(r.name)).length,
   fonts: [...new Set([...document.fonts].filter(f => f.status === 'loaded').map(f => f.family))],
   recs: [...document.querySelectorAll('.t-rec')].map(r => r.id + ':' + getComputedStyle(r).display),
   whatsapp: opened })
```
Норма: github 0, шрифты сайта загружены, галерея `display:none`, WhatsApp с номером (у каркасов без кнопок WhatsApp – пусто, это нормально). Картинки ниже первого экрана в фоновой вкладке не грузятся (ленивая загрузка) – это не ошибка; глазами проверяй скриншотом после прокрутки. Один скриншот первого экрана – ученику вместе со ссылкой.

## Ловушки (02–03.10.2026, прогон и репетиция на автомойке)

- Расширение после переустановки приложения может остаться привязанным к старому аккаунту Claude – «not connected». Лечится выходом и входом на claude.ai в Chrome.
- Окно Chrome свёрнуто – скриншоты не снимаются, клики уходят в пустоту. Попроси развернуть окно Chrome.
- Тильда держит имя файла в ссылке (`static.tildacdn.pub/tild…/hero.webp`), webp принимает. Скрипт сопоставляет по имени – файлы не переименовывай.
- Галерею не удалять: картинки живут в ней, при передаче страницы заказчику уезжают вместе со страницей.
- Пробный период Тильды (14 дней) переносу не мешает: T123 доступен на пробном Personal.

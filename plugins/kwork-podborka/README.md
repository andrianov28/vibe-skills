# kwork-podborka

Скилл курса «Вайб-сайты». Ученик пишет Клоду «подбери заказы», скилл сам читает биржу проектов Kwork (рубрика «Создание сайта» и поиск по слову «сайт»), отбирает свежие простые сайты с нуля в бюджете 3–30 тыс. ₽ и пишет черновики откликов.

Логин и пароль не нужны: скрипт читает открытую страницу биржи. Откликаться скилл не умеет – отклик отправляет сам ученик.

Установка в Claude Code:

```
/plugin marketplace add andrianov28/vibe-skills
/plugin install kwork-podborka@vibe-skills
```

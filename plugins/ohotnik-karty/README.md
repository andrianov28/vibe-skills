# ohotnik-karty – «Охотник: клиенты с Карт»

Скилл курса «Вайб-сайты»: сам находит на Яндекс.Картах бизнесы выбранной ниши в любом городе, у которых есть карточка, отзывы и звонки, но нет сайта (или вместо сайта заглушка), читает отзывы, цены и контакты, считает индекс горячести, находит крючок в отзывах и пишет первое сообщение владельцу.

Итог – «Карта охоты»: HTML-отчёт с базой клиентов (куда написать: Телеграм, WhatsApp, Макс, ВК), сообщением с кнопкой «Скопировать», статусами и местом под ссылку на демо-сайт, который дальше собирает скилл «Вайб-сайт». Рядом `база.csv` для учёта. Только открытые данные Карт, никаких покупных баз. Звонить не нужно – работаем в переписке.

## Установка

```
/plugin install ohotnik-karty@vibe-skills
```

или фразой в приложении Claude: «включи плагин ohotnik-karty@vibe-skills в enabledPlugins моего settings.json». Нужен встроенный браузер приложения Claude Code (скилл сам открывает Карты) и Node.js для сборки отчёта.
